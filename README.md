# JLPT Review

> 把“看得懂的日语”，变成真正能够主动还原的句子。

JLPT Review 是一款面向中文日语学习者的自托管句子重组与间隔复习应用。输入中文提示和日语原句，系统会在本地自动拆分词块、生成假名注音，并将句子转化为主动回忆练习；完成练习后，再由 FSRS 根据你的真实表现安排后续复习。

它不是一套固定题库，而是一套帮助你消化自己手中材料的学习工具。JLPT 例句、教材句子、语法笔记、错题、影视台词和个人表达，都可以逐渐整理成属于自己的日语句库。

**本地分词 · 自动评分 · FSRS 复习 · 练习报告 · 学习统计 · Docker 部署**
